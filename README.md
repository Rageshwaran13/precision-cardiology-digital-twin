> **Research prototype:** This project demonstrates a cardiac monitoring workflow using synthetic patient records and wearable-style physiological signals. It is not clinically validated and must not be used for medical diagnosis, treatment, or real-world clinical decision-making.

## Project Overview

Precision Cardiology Digital Twin combines synthetic electronic health records (EHR), wearable-style physiological time-series data, machine learning, and interactive 3D heart visualization in a unified research dashboard.

The prototype demonstrates how simulated patient information and physiological trends can be processed into a model-generated cardiac-anomaly risk estimate and presented through an interactive clinical-style interface.

## Key Features

* **Synthetic Patient Data:** Generation of simulated clinical records and wearable-style physiological measurements.
* **Physiological Signal Analysis:** Exploration of heart rate, heart-rate variability, oxygen saturation, and other generated measurements.
* **Feature Engineering:** Integration of clinical information with time-series features and rolling summaries.
* **Machine Learning:** Gradient-boosting classification for a synthetic cardiac-anomaly demonstration task.
* **Interactive Dashboard:** Patient summaries, telemetry charts, risk visualization, and supporting information.
* **3D Heart Visualization:** Interactive anatomical visualization using Three.js and WebGL.
* **Reproducible Setup:** Scripts for generating demonstration data and training the model.
