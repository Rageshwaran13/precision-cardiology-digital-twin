# Third-party assets and attribution checklist

Before publishing this repository publicly, verify the origin and redistribution terms of every non-code asset bundled with the project.

| Asset | Current repository location | Action before public release |
|---|---|---|
| Three.js library | `dashboard/static/three.min.js` | The bundled file contains an MIT SPDX notice. Keep the original copyright and license notices. |
| GLTFLoader | `dashboard/static/GLTFLoader.js` | Verify the matching upstream Three.js version and preserve the applicable upstream notices. |
| 3D heart model | `dashboard/static/heart_model.glb` | Confirm the model's creator/source and that redistribution is permitted. Add required attribution or replace it if permission is unclear. |
| Heart illustration | `dashboard/static/digital_twin_heart.jpg` | Confirm the image's source and redistribution rights; add attribution or replace it if required. |
| Presentation and blueprint | `docs/` | Confirm that any embedded imagery or third-party content may be publicly shared. |

This file is a checklist, not a claim that all included assets have been independently cleared for redistribution. No license has been selected for the project as a whole.
